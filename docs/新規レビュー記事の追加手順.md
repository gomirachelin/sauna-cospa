# 新しいサウナのレビュー記事を追加する手順

新しく1軒ぶんのレビューを追加するときに、**どのファイルを・どの順番でさわればいいか**をまとめたメモです。
専門用語はできるだけ使っていません。上から順にやれば1軒追加できます。

> 作業をお願いするときは、このファイルを見せて「この手順で〇〇（施設名）を追加して」と伝えればOKです。

---

## 追加する前に決めておくこと

| 決めること | 例 | どこで使うか |
|---|---|---|
| 施設名 | `神戸サウナ` | 全部 |
| フォルダ名（slug） | `神戸サウナ` | ページのURLになる |
| エリア | `神戸` | 一覧の表示 |
| 平日料金 | `3100`（円） | 一覧の表示・コスパ計算 |
| 主要都市からの所要時間 | `15`（分） | 一覧の表示 |
| 1時間あたり料金 | `172`（円/h） | 一覧の表示 |
| 総合／コスパ／タイパ スコア | `66` / `33.4` / `36.5` | ランキング・一覧の並び順 |
| 10項目それぞれの点数 | ①サウナ 8.0 …⑩ホスピタリティ 7.0 | EVALUATIONページ |
| 公式サイトURL | `https://www.kobe-sauna.co.jp/` | 「公式」ボタン |
| 閉店しているか | 開いていれば `false` | 「閉店」バッジ |

---

## 手順

### 1. 記事ページ本体をつくる

1. サイトのフォルダの一番上に、**施設名のフォルダ**を新しくつくる（例：`神戸サウナ`）。
2. すでにある似た記事（例：`神戸サウナ/index.html`）を**コピー**して、新しいフォルダに `index.html` という名前で入れる。
3. その `index.html` の中の次の場所を、新しい施設の内容に書きかえる。
   - `<title>` … `施設名 | GOMIRACHELIN`
   - `<meta name="description" ...>` … 検索結果に出る説明文
   - `<link rel="canonical" href="...">` … `https://gomirachelin.github.io/sauna-cospa/施設名/` にあたるURL（日本語部分はURLエンコードしてもそのままでも可）
   - `<h1>` … 施設名
   - 本文（点数カード、◎良い点／△惜しい点、レビュー本文、アクセス・関連リンクなど）

> **ポイント**：ヘッダー（上のメニュー）、フッター（下のリンク・Amazon表記）、および「サウナのおとも［PR］」枠（`<!-- AMAZON-BOX:START -->`〜`<!-- AMAZON-BOX:END -->`）は、他の記事からコピーしたままで大丈夫です。共通の見た目は `css/site.css` が担当しています。

### 2. ランキングの正本データに載せる（`data/rankings.json`）

ランキング（`ランキング/index.html`）と10項目別ランキング（`10項目別ランキング/index.html`）は、**HTMLを直接書きかえず**、`data/rankings.json` の `facilities` 配列を編集します。

- すでに名前だけ載っている施設に記事を追加する場合は、その施設の `"slug": ""` を `"slug": "施設名"` に書きかえ、10項目の点数 `"axes": {"a1": 8.0, ..., "a10": 7.0}` を足します。
- 新しい施設を丸ごと足す場合は、次の形で1件追加します。

```json
{
  "name": "神戸サウナ",
  "pref": "神戸",
  "price": 3100,
  "min": 15,
  "yen_h": 172,
  "total": 66,
  "cospa": 33.4,
  "taipa": 36.5,
  "slug": "神戸サウナ",
  "closed": false,
  "official": "https://www.kobe-sauna.co.jp/",
  "axes": {
    "a1": 8.0, "a2": 8.0, "a3": 7.0, "a4": 7.0, "a5": 8.0,
    "a6": 7.0, "a7": 7.0, "a8": 7.0, "a9": 7.0, "a10": 7.0
  }
}
```

- `slug` は **手順1でつくったフォルダ名と完全に同じ**にすること。ここがずれるとリンク切れになります。
- 保存したら、次のコマンドで2つのランキングページを自動更新・確認します（詳しくは `docs/ランキング更新手順.md`）。

```bash
python3 scripts/build_rankings.py
python3 scripts/build_rankings.py --check
```

### 3. ページの一覧データに追加する（`data/urls.json`）

配列に1件足します。`date` は公開日です。

```json
{
  "id": 999,
  "slug": "神戸サウナ",
  "title": "神戸サウナ",
  "link": "https://gomirachelin.github.io/sauna-cospa/%e7%a5%9e%e6%88%b8%e3%82%b5%e3%82%a6%e3%83%8a/",
  "date": "2026-08-23T05:25:30",
  "type": "post"
}
```

- `link` のギザギザした文字列は、日本語URLをコンピュータ用に変換したものです。分からなければ `https://gomirachelin.github.io/sauna-cospa/施設名/` のままでも一覧の表示には影響しません。

### 4. レビュー一覧ページを作り直す（自動）

サイトのフォルダで次のコマンドを実行します。`reviews/index.html` が最新の内容に作り直され、URLデータの整合性も確認できます。

```bash
python3 scripts/gen_reviews.py
python3 scripts/check_url_data.py
```

- `ランキング/index.html` の `FACILITIES` と `data/urls.json` を読んで、**記事フォルダが実際にあるものだけ**を新着順に並べます。
- 手作業で `reviews/index.html` を編集しないでください（次に実行したとき上書きされます）。

### 5. 地図データに追加・更新する（`data/map-facilities.json`）

地図にも新しい施設や記事リンク、ピン（緯度・経度）を載せるときは、`data/map-facilities.json` を編集してから次を実行します（詳しくは `docs/地図データ更新手順.md`）。

```bash
python3 scripts/build_map_data.py
python3 scripts/build_map_data.py --check
```

### 6. サイトマップに追加する（`sitemap.xml`）

検索エンジンに新しいページを知らせるファイルです。次の4行を足します。

```xml
  <url>
    <loc>https://gomirachelin.github.io/sauna-cospa/施設名/</loc>
    <lastmod>2026-08-23</lastmod>
  </url>
```

### 7. 確認してGitHubで公開する

確認するところ:
- 新しい記事ページが開くか
- `ランキング` に載っていて、施設名を押すと記事に飛ぶか
- `reviews`（レビュー一覧）に載っているか
- `10項目別ランキング`（EVALUATION）の各項目に入っているか

確認できたら、`docs/STATE.md` に作業内容を記録し、変更したファイルをまとめて GitHub（`gomirachelin/sauna-cospa` の `main` ブランチ）へ反映（コミット＆push）します。数分で `https://gomirachelin.github.io/sauna-cospa/` に自動公開されます（ConoHaサーバーへのアップロードは不要です）。

## 迷ったときのチェックリスト

- [ ] フォルダ名と `slug` が一字一句同じか（全角・半角、`-` の有無に注意）
- [ ] `data/rankings.json` を更新して `python3 scripts/build_rankings.py` を実行したか
- [ ] `python3 scripts/gen_reviews.py` と `python3 scripts/check_url_data.py` を実行したか
- [ ] `sitemap.xml` に `https://gomirachelin.github.io/sauna-cospa/〜` のURLを足したか
- [ ] `docs/STATE.md` に追加記録を書いたか
